# Generate a SQL query string from a CSV

> **Archived learning exercise (2022).** Kept as-is; not maintained and not part of the current portfolio.

A single-cell notebook (`12 .ipynb`) that reads rows from a CSV file with the standard library `csv` module and assembles them into a SQL query string, so a long `IN (...)` or `VALUES` list does not have to be typed by hand.

## Run it

Open the notebook in Jupyter. It needs only the Python standard library and a CSV file to point it at.
